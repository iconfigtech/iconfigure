# iConfigure

Professional website and digital presence for iConfigure, a Dubai-based business focused on iPhone repair, refurbishment, and board-level diagnostics.

## Overview

iConfigure provides services for:

- iPhone repair and restoration
- Screen, battery, housing, and water-damage recovery
- Refurbishment and B2B device returns
- Trade-in and graded-stock handling
- Board-level diagnostics and hardware-level troubleshooting

The repository contains the public landing page for the brand and acts as the central digital hub for the company's online presence.

## Business profile

iConfigure is positioned as a technology-led repair and refurbishment business serving Dubai and broader UAE markets. The brand focuses on both consumer repair and business-to-business refurbishment workflows, with emphasis on technical recovery and quality control.

## Technology stack

This project is a lightweight static web experience built with:

- HTML5
- CSS3
- JavaScript
- Three.js (used for the landing-page visual animation)
- GitHub Pages for hosting

This is intentionally simple and fast, with no build step required for standard deployment.

## Local development

To preview the project locally:

```bash
cd /path/to/iconfigure
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

The landing page is designed to be served through GitHub Pages or a custom domain. For production branding, it is recommended to use a dedicated business domain such as:

- `iconfigure.ae`
- `iconfigure.com`
- `www.iconfigure.ae`

A custom domain gives the business a more professional online identity and improves trust for customers and partners.
